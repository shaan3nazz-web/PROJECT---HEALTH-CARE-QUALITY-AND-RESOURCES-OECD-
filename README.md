# AMI 30-Day Mortality Analysis (OECD Countries)

## Project Overview
This project analyzes healthcare quality indicators with a focus on AMI (acute myocardial infarction) 30-day mortality outcomes.  
It transforms raw OECD dataset into a robust analytical framework for benchmarking performance, identifying disparities, and guiding evidence-based policy interventions.

## Data Preparation
- **Cleaning**: Standardized column names, removed unnecessary fields, handled missing values and outliers.
- **Feature Engineering**: Added 3 new columns to enrich equity analysis, confidence interval precision checks, and regional/income group comparisons.

## Exploratory Analysis
- **Univariate**: Histograms of indicator values and CI ranges, line plots of gender counts, pie chart of mortality category distribution.
- **Bivariate**: Scatter plots, box plots, line plots, bar plots, violin plots to explore relationships across age, gender, and regions.
- **Multivariate**: Box plots of country averages by mortality category and WHO region, choropleth with income group highlights, correlation heatmaps, pairplots, 3D scatter plots, and parallel coordinates.

## Key Insights
- Decline in mortality rates from 2000–2018, followed by stabilization.
- Equity gaps across gender and age groups.
- Regional disparities: Europe lower averages, Americas higher.
- Strong correlations between estimates and confidence intervals.

## Conclusion
Through systematic cleaning, feature engineering, and advanced exploratory analysis, this project delivers a holistic understanding of AMI 30-day mortality outcomes.  
The dataset now supports equity analysis, precision checks, and contextual comparisons across WHO regions and income groups.  
It serves as a powerful tool for benchmarking healthcare systems, identifying disparities, and guiding evidence-based policy interventions globally.
